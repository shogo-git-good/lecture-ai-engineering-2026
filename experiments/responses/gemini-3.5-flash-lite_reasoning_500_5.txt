製品AとBの最適な生産個数を求めるため、条件を数式で整理し、すべての組み合わせを検証して利益が最大となる解を導きます。

### 1. 条件の整理
* **製品A**: 利益300円、作業時間2時間
* **製品B**: 利益400円、作業時間3時間
* **制約条件**: 合計作業時間は12時間以内、生産個数は0以上の整数
* **目的関数**: 総利益 $Z = 300A + 400B$ を最大化する（$A, B$ は非負整数）

作業時間の制約式は以下のようになります。
$$2A + 3B \le 12$$

### 2. 可能な組み合わせの検証
製品Bの生産数 $B$ を $0$ から最大値（$12 \div 3 = 4$）まで変化させ、条件を満たす最大の $A$ を求めてそれぞれの総利益を計算します。

1. **$B = 0$ の場合**
   * $2A + 3(0) \le 12 \rightarrow 2A \le 12 \rightarrow A \le 6$
   * 可能な最大個数：$A = 6, B = 0$
   * 総利益：$300 \times 6 + 400 \times 0 = 1800$ 円

2. **$B = 1$ の場合**
   * $2A + 3(1) \le 12 \rightarrow 2A \le 9 \rightarrow A \le 4.5$
   * 整数条件より最大個数：$A = 4, B = 1$ （作業時間：$2(4) + 3(1) = 11$時間）
   * 総利益：$300 \times 4 + 400 \times 1 = 1600$ 円

3. **$B = 2$ の場合**
   * $2A + 3(2) \le 12 \rightarrow 2A \le 6 \rightarrow A \le 3$
   * 可能な最大個数：$A = 3, B = 2$ （作業時間：$2(3) + 3(2) = 12$時間）
   * 総利益：$300 \times 3 + 400 \times 2 = 1700$ 円

4. **$B = 3$ の場合**
   * $2A + 3(3) \le 12 \rightarrow 2A \le 3 \rightarrow A \le 1.5$
   * 整数条件より最大個数：$A = 1, B = 3$ （作業時間：$2(1) + 3(3) = 11$時間）
   * 総利益：$300 \times 1 + 400 \times 3 = 1500$ 円

5. **$B = 4$ の場合**
   * $2A + 3(4) \le 12 \rightarrow 2A \le 0 \rightarrow A = 0$
   * 可能な最大個数：$A = 0, B = 4$ （作業時間：$3(4) = 12$時間）
   * 総利益：$300 \times 0 + 400 \times 4 = 1600$ 円

### 3. 結論
各ケースの総利益を比較すると、**製品Aを6個、製品Bを0個**生産した場合の1800円が最大となります。

**理由**:
製品Bは1個あたりの利益が高いものの、1時間あたりに換算すると、Aは「300円÷2時間＝150円/時間」、Bは「400円÷3時間＝約133.3円/時間」となり、時間効率の面で製品Aの方が優れています。そのため、限られた12時間の作業時間をすべて効率の良い製品Aの生産に割り当てることで、最大利益を得ることができます。
