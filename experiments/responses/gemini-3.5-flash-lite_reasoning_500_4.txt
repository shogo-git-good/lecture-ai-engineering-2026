製品Aの生産個数を $x$、製品Bの生産個数を $y$ とします。問題文の条件を数式で表すと、以下のようになります。

1. **目的関数（最大化する利益）**:
   $Z = 300x + 400y$ （円）

2. **制約条件（作業時間）**:
   $2x + 3y \le 12$ （時間）

3. **非負・整数条件**:
   $x, y$ は $0$ 以上の整数

$x$ と $y$ は 0以上の整数であるため、制約条件を満たすすべての組み合わせを検証することが可能です。作業時間の制約 $2x + 3y \le 12$ に当てはまる $(x, y)$ の組み合わせを洗い出し、それぞれの利益を計算します。

* $x = 0$ のとき：
  $3y \le 12 \rightarrow y$ は $0, 1, 2, 3, 4$
  * $(0, 0)$：利益 $= 300(0) + 400(0) = 0$ 円
  * $(0, 1)$：利益 $= 300(0) + 400(1) = 400$ 円
  * $(0, 2)$：利益 $= 300(0) + 400(2) = 800$ 円
  * $(0, 3)$：利益 $= 300(0) + 400(3) = 1200$ 円
  * $(0, 4)$：利益 $= 300(0) + 400(4) = 1600$ 円

* $x = 1$ のとき：
  $2 + 3y \le 12 \rightarrow 3y \le 10 \rightarrow y$ は $0, 1, 2, 3$
  * $(1, 0)$：利益 $= 300(1) + 400(0) = 300$ 円
  * $(1, 1)$：利益 $= 300(1) + 400(1) = 700$ 円
  * $(1, 2)$：利益 $= 300(1) + 400(2) = 1100$ 円
  * $(1, 3)$：利益 $= 300(1) + 400(3) = 1500$ 円

* $x = 2$ のとき：
  $4 + 3y \le 12 \rightarrow 3y \le 8 \rightarrow y$ は $0, 1, 2$
  * $(2, 0)$：利益 $= 300(2) + 400(0) = 600$ 円
  * $(2, 1)$：利益 $= 300(2) + 400(1) = 1000$ 円
  * $(2, 2)$：利益 $= 300(2) + 400(2) = 1400$ 円

* $x = 3$ のとき：
  $6 + 3y \le 12 \rightarrow 3y \le 6 \rightarrow y$ は $0, 1, 2$
  * $(3, 0)$：利益 $= 300(3) + 400(0) = 900$ 円
  * $(3, 1)$：利益 $= 300(3) + 400(1) = 1300$ 円
  * $(3, 2)$：利益 $= 300(3) + 400(2) = 1700$ 円（作業時間: $2\times3 + 3\times2 = 12$ 時間）

* $x = 4$ のとき：
  $8 + 3y \le 12 \rightarrow 3y \le 4 \rightarrow y$ は $0, 1$
  * $(4, 0)$：利益 $= 300(4) + 400(0) = 1200$ 円
  * $(4, 1)$：利益 $= 300(4) + 400(1) = 1600$ 円

* $x = 5$ のとき：
  $10 + 3y \le 12 \rightarrow 3y \le 2 \rightarrow y = 0$
  * $(5, 0)$：利益 $= 300(5) + 400(0) = 1500$ 円

* $x = 6$ のとき：
  $12 + 3y \le 12 \rightarrow 3y \le 0 \rightarrow y = 0$
  * $(6, 0)$：利益 $= 300(6) + 400(0) = 1800$ 円（作業時間: $2\times6 = 12$ 時間）

### 結論
検証の結果、利益が最大となるのは **製品Aを6個、製品Bを0個** 生産する場合です。このときの利益は **1800円** となります。

**理由**:
製品Bは1時間あたりの利益が約133円（400円÷3時間）であるのに対し、製品Aは150円（300円÷2時間）と、時間効率がAの方が高いためです。作業時間12時間をすべて製品Aに割り当てることで、無駄なく最大の利益を得ることができます。
